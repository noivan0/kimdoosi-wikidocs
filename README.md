# 김두시의 AI 활용 노트

AI를 켜 두고도 첫 줄에서 멈추는 사람을 위한 실전 활용 노트입니다. 프롬프트를 많이 모으는 대신, 업무 자동화부터 콘텐츠 제작, 무료 API 연동까지 실제로 써먹는 사례를 골라 "무엇을 넣고, 무엇을 시키고, 무엇으로 통과를 판정하는지"를 순서대로 정리해 계속 추가합니다.

메일과 회의록, 주간보고, 영수증 정산, 카드뉴스, 그리고 무료 API 연동까지 다룹니다. 모든 장은 같은 구조를 따릅니다. 언제 쓰는 루틴인지, 그대로 붙여 넣을 프롬프트 원문, 통과와 탈락을 가르는 판정 기준, 그리고 대부분이 여기서 미끄러지는 지점입니다.

이 책은 특정 유료 서비스를 전제로 하지 않습니다. 무료 요금제로 시작할 수 있는 조합만 씁니다. 도구 이름이 바뀌어도 순서는 남기 때문에, 도구를 갈아타도 그대로 쓸 수 있습니다.

## 이 책에서 지키는 세 가지

- 지어내지 않기. 입력에 없는 사실은 결과물에 넣지 않고, 불확실하면 "확인 필요"로 남깁니다.
- 지우는 순서. 결과물이 어색할 때 무언가를 더 얹지 않고 먼저 뺍니다.
- 검수 한 줄. AI의 "다 됐어요"를 믿지 않고, 사람이 마지막에 한 번 세어 봅니다.

## 이런 분께 맞습니다

- AI를 결제해 두고도 한 달에 몇 번 열지 않는 직장인
- 회사 문서, 정산, 콘텐츠를 혼자 처리하는 1인 사업자
- 자동화를 시작하고 싶은데 무엇부터 맡겨야 할지 모르는 분
- 프롬프트 모음은 많은데 매번 처음부터 다시 쓰게 되는 분

## 읽는 순서

1장에서 맡겨도 되는 일인지 판단하는 기준을 먼저 세우고, 2장부터 6장까지는 업무별 루틴을 하나씩 따라 합니다. 7장은 사람이 손으로 반복하던 일을 코드로 넘기는 단계이고, 8장은 여기까지 온 루틴을 4주 안에 습관으로 굳히는 순서입니다.

각 장의 프롬프트는 복사해서 바로 쓰도록 원문 그대로 실었습니다. 더 자주 쓰는 루틴과 복사용 원문은 아래 페이지에 모아 두었습니다.

- 실전 루틴과 프롬프트 원문: https://kimdoosi.com/archive
- 무료 API 가이드: https://kimdoosi.com/exaone
